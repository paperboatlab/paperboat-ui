The Paperboat look as React components (`@paperboatlab/ui`): the design tokens, keys, pills, the
spinner, the rail and the page rail, panels, dialogs, menus and the menu bar, toasts, the theme picker, the floating
search, the app marks with their idle fold, the file tree (`/files`), plots, the Scope and the instrument frame (`/plot`,
`/scope`), help, messages, the console, the run dock, the splash, the value table and the package panel (`/packages`), the note graph (`/graph`: Obsidian's graph on React Flow, a settling force layout), math (`mathHtml`, KaTeX), media (`/media`: a video and sound player, an image editor that crops and rotates), the node canvas on React Flow (`@paperboatlab/ui/canvas`: wire routing,
layout, ports, snapping, undo), and the code editor (`@paperboatlab/ui/editor`: languages in
`src/editor/lang/` — Julia, Python, Modelica, JSON, TOML, Markdown, plain text — and its themes
in `src/editor/themes/`: Fleet by default, and Paperboat; the tab menu's rules in `src/editor/tabs.ts`). Every [Paperboat](https://github.com/paperboatlab/paperboat) app uses it
(the Launcher, Malachite, Simplicial, Articula, Julix). It holds no app logic. It replaces
[paperboat-shared-legacy](https://github.com/paperboatlab/paperboat-shared-legacy).

**The UI example:** [ui-example.html](ui-example.html) draws every token, pattern and component from
`src/tokens.css`, the one source; read it before designing any app UI (generated by
`agent-docs/rebrand/logogen/src/brand.jl`). The plan: `agent-docs/rebrand/REBRAND.md` · **Icons:** one registry,
`agent-docs/rebrand/icons.toml`; `npm run icons` writes `src/icons.ts` from it.

## Use

```sh
echo "@paperboatlab:registry=https://npm.pkg.github.com" >> .npmrc
npm install @paperboatlab/ui
```

```tsx
import "@paperboatlab/ui/tokens.css";
import "@paperboatlab/ui/ui.css";
import { Key, Rail, ThemePicker } from "@paperboatlab/ui";
```

Each app sets `data-app` on `<html>` (`paperboat`, `simplicial`, `articula`, `julix`, `malachite`) for
its accent.

## Check

```sh
npm ci
npm run typecheck
npm test
npm run demo        # every component, light and dark: serve demo/ and open index.html
```

## CI

[ci.yml](.github/workflows/ci.yml) typechecks and tests every push; a `v*` tag publishes the package to
GitHub Packages.
